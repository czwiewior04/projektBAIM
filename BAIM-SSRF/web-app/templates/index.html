Co demonstruje ten lab?

Backend pobiera URL podany przez użytkownika. W Vulnerable Mode można wskazać wewnętrzny serwis dostępny z sieci kontenerów. Protected Mode dopuszcza wyłącznie HTTPS do example.com.
